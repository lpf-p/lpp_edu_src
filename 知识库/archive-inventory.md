## 三、给后续整理者的操作提示

### 3.1 怎么判副本（三步，可在 ima 内直接操作）
1. **先做标题归一化**：剥掉后缀 `_(n)`、`(n)`、` (n)`、`_20210506xxxxxx`、`-n`，以及"（已看）/（不打码）/（水印）"等标记，得到"归一化标题"。
2. **再比 `file_size`**：归一化标题相同**且 size 完全相同** → 判为副本，**只留一份**（建议留"无后缀"或最早的那份）。
3. **最后看 media_id**：若两份 media_id 完全相同（如 `脱敏不安全资源调用.docx` 与其 `_(2)`），说明是**同一文件被重复挂载**，删哪一份都安全。

### 3.2 什么情况**不能**删
- **同标题、size 不同**（见 §2.2，25 组）：一律视为不同版本（完整版/已看版、原图版/压缩版），**各自保留**；本次列出的 25 组即"不许删名单"。
- **同 size、标题不同**（见 §2.2 末注）：如 `网易 SRC 漏洞挖掘总结.pdf` = `SRC挖掘那些事.pdf`（均 3891937）等，**可能是换名重传、也可能是真不同**，需人工打开确认后再合并。
- **带 `(1)` 但 size 不同的"压缩版"**：如 `清华大学 教育漏洞报告平台 (1).pdf`(652259) 与 `.pdf`(457090)，前者通常是"原图/完整"、后者是"压缩/已看"，**不要以为是副本就删**。
- **任何"（已看）"标记的 doc**：它往往与同名 pdf 成对（EduSRC 单点提交），**是两种格式，不是副本**。

### 3.3 images 何时有用
- **截图 = 证据/线索，不是素材**：只有当①它是某个**已知案例的唯一配图**（如同济越权 5 图 → `edusrc-cases.md` §2.8），或②文件名含**实际目标线索**（`华理`/`交大`/`新疆交通`/`教育局护网`）时才保留。
- **哈希命名 / `Untitled` / `1~4.jpg` 类**：无上下文，**除"同济 5 图"外基本无单独价值**；若某报告正文引用了它，应按"报告 → 图片"关联保留，而不是凭文件名。
- **txt/xlsx 类**：`渗透字典.txt`、`资产漏洞.txt` 是**可复用工具资产**，优先保留；其余 <1KB 的 txt 与测试型 xlsx 直接丢弃。
- **跨格重复**：图片与报告可能同时出现在「其他」与其他类目（越权/EduSRC），**清理前先跑一次全库同名/同 size 汇总**，避免把别处仍需要的图删掉。
