## 二、撞库与喷洒手法

**账号字典构造**
- 管理员习惯：`admin` / `root` / `test` / `administrator` / `88888` / `admin123` / `root123`（京东18期）。
- 与系统强相关：`system`（SOGo）、`admin`（各类后台）、`klcheng`（企业邮箱前缀）。
- 从信息泄露/官网收集真实用户名：工号、手机号、姓名全拼/缩写。

**口令字典构造**（京东18期归纳）
1. 连续/重复数字：`123123` `123456` `111111` `222333`；
2. 连续/重复字母：`aaa` `abc` `abcdef` `zyx`；
3. 键盘序列：`1qaz@wsx` `qwert` `asdfghjkl` `147258369`；
4. 日期/生日：`800128` `2012` `19251120`；
5. 用户名相关：`newdoone`(公司名) `shaoyuanming`(姓名) `sym`(缩写) `oa`(产品) 手机号；
6. 特殊含义：`520` `1314` `woaini`；
7. 通用：`root` `abc123!` `administrator` `test`。
- 组合生成：`公司名+数字`、`字母+键盘符`、`键盘符+特殊义`、`用户名+年份`。

**喷洒策略**
- 横喷：固定弱口令（如 `123456`/`admin123`）× 多个用户名；纵喷：固定账号 × 常见口令表。
- 监控盲区：不只盯 Web 登录，POP/IMAP（邮件）、RDP、SSH、数据库端口都要试（京东19期）。

**锁定与验证码规避**
- 限制登录失败次数、错峰低速、分散源 IP；验证码仅在 Web 有，邮件/接口层常无。

**判定成功/失败特征**
- 成功：302 跳转带新 cookie、返回"欢迎/后台首页"、无错误回显、接口返回用户数据。
- 失败：回显"用户名或密码错误"、停留登录页、HTTP 200 但 body 含错误串。

## 三、默认口令之外的"等价初始态"

- **身份证后六位**：教育侧高价值初始口令（统一身份认证/学工系统常见）。
- **工号 / 学号**：直接作为初始口令或前缀。
- **手机号后四位**：互联网应用常见初始口令。
- **企业名+年份**：如 `公司名2023`。
- **统一默认 `123456`**：新疆交职院全校师生统一认证默认即 `123456`，且学生信息系统可**免统一认证**直接进入内网信息门户，等价于"任意师生账号可登录+管理员权限"。
- **首次登录强改密绕过**：部分系统强改密逻辑可被"先登录再调用接口/跳过前端"绕过，需结合越权（如甲鼎 PosiID 越权）扩大危害。

## 四、按目标类型的排查 Checklist

- **外网暴露服务**：SSH(22) / RDP(3389) / MySQL(3306) / Redis(6379) / MongoDB / PostgreSQL —— 内外网隔离好则少，暴露即高危。
- **中间件与管理后台**：Tomcat / Weblogic / Nacos / Jenkins / Zabbix(`Admin/zabbix`) / Nexus / Druid(`/druid/login.html`) / phpMyAdmin(`/phpmyadmin/`) / 各类 `/admin`。
- **国产 OA**：致远/泛微/通达/蓝凌 默认口令与绕过。
- **网络设备/网关**：锐捷锐易网关 `admin:admin`（`:6060` 等）。
- **安防/摄像头**：Q-see 等 `:8080` ONU WEB。
- **动环/机房监控**：XBROTHER `admin:123456`（`:30001`）。
- **停车/门禁/一卡通**：道尔 `admin:123456`。
- **业务运营后台**：第三方代运系统（如 vivo `lzftah.com`、掌如填报系统）常留默认口令。
- **教育侧高价值**：统一身份认证 / 教务 / 学工 / 一卡通 / 财务 / 研究生系统；初始口令常为身份证后六位或 `123456`；邮件系统（SOGo 等）常带默认管理员账号。

## 七、厂商定级尺度观察

- 弱口令常被判"低危"或忽略。**升档论证要点**：
  1. **后果链**：不要只报"弱口令"，要证明打进去后能做什么——如教育局护网案（弱口令→内网→MS17-010→抓凭证→泄露 740 条敏感数据），直接判高。
  2. **数据敏感性**：教育侧命中即触达全校师生身份证/学籍/财务（新疆交职院 882 条），属高敏，应升档。
  3. **默认口令批量性**：锐易网关/XBROTHER/道尔等"出厂默认+外网批量"属配置默认风险，CNVD 直接通报。
  4. **被忽略的反例**：麦当劳云鼎智能因"供应商资产/第三方/域名解析有误"被判不在奖励范围——**资产归属与授权边界**是 SRC 定级关键，提交前需确认资产归属与测试授权。
  5. 强随机口令却可登录（浙大能源系统），应论证"口令疑似源于配置文件/源码泄露"，属信息泄露衍生，定级高危。
