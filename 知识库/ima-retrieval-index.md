## 〇、通用调用方式（照抄即可）

```
# 1) 拉目录清单（folder_id 必须带 folder_ 前缀，否则报"文件夹不存在"）
get_knowledge_list(
  knowledge_base_id = "7492290188703512",
  folder_id         = "<下表 folder_id>",
  limit             = 50,          # 上限 50，超过报错
  sort_type         = "TITLE_SORT_TYPE",
  cursor            = ""           # 第一页空串，之后用上一页 next_cursor，直到 is_end=true
)

# 2) 读全文
fetch_media_content(media_id = "<清单里的 media_id>")
```

**三条回查路径（按成本从低到高）**
1. **有报告名** → 直接在 ima 客户端搜索标题（最快，标题即报告名，§各文件「案例索引」列里有）。
2. **只有章节 / 手法** → 用本表给的**检索关键词**在对应目录里翻，或 ima 全局搜索关键词。
3. **只知道系统/厂商** → 用 `vendor-system-cases.md` 的指纹表定位系统名，再回查。

> ⚠️ 回查时注意**副本**：`title` 结尾带 `(n)` / `_(n)` / `_20xxxxxxxxxxxx` 的是副本；`file_size` 相同 ⇒ 内容逐字相同，读任一份即可；**`file_size` 不同则是不同内容，必须分别读**。
